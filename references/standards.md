# Standards and source authority

Phase 1 targets WCAG 2.2 A/AA barriers within its visual-access inventory. It is not a complete conformance assessment. Explanations in this package paraphrase and interpret linked authority; the normative source controls if wording differs.

| Source | Status and version/date | Use |
|---|---|---|
| [WCAG 2.2](https://www.w3.org/TR/2024/REC-WCAG22-20241212/) | W3C Recommendation, 12 December 2024 | Normative success criteria and exceptions; A/AA baseline |
| [WAI-ARIA 1.2](https://www.w3.org/TR/2023/REC-wai-aria-1.2-20230606/) | W3C Recommendation, 6 June 2023 | Normative roles, states, properties and author requirements |
| [ACT Rules Format 1.1](https://www.w3.org/TR/2026/REC-act-rules-format-1.1-20260205/) | W3C Recommendation, 5 February 2026 | Inspiration for explicit applicability, expectations and transparent evidence; A11yVision rules do not claim formal ACT publication/validation |
| [W3C ACT rules](https://www.w3.org/WAI/standards-guidelines/act/rules/) | Informative published rules, living collection | Reference test approaches and known applicability limits |
| [WCAG 2.2 Understanding](https://www.w3.org/WAI/WCAG22/Understanding/) | Informative guidance, living collection | Intent, examples and interpretation; not normative criterion text |
| [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) | Informative guidance, living collection | Widget patterns and keyboard interaction; examples require adaptation and testing |
| [AccName 1.1](https://www.w3.org/TR/2018/REC-accname-1.1-20181218/) | W3C Recommendation, 18 December 2018 | Stable normative accessible-name/description computation reference |
| [AccName series](https://www.w3.org/TR/accname/all/) | AccName 1.2: Working Draft, 27 August 2026 at the 3 October 2026 review | Monitor only; do not silently replace AccName 1.1 or treat the draft as a final Recommendation |
| [HTML](https://html.spec.whatwg.org/multipage/) | WHATWG Living Standard | Native semantics and behavior as needed |
| [HTML accessibility mappings](https://www.w3.org/TR/html-aam-1.0/) | Working Draft, 23 September 2026; check maturity before use | Supplementary browser/platform mappings, not a replacement for stable normative authority |

| [CSS Color Adjustment Level 1](https://www.w3.org/TR/2025/CR-css-color-adjust-1-20251216/) | Candidate Recommendation Snapshot, 16 December 2025; not a final Recommendation | Supplementary forced-colors platform behavior for the advisory rule |

The dated Recommendation links pin the Phase 1 baseline. Latest series URLs in rule files aid maintenance. Check publication status when updating sources; a latest-version redirect is not permission to replace the baseline silently.

## Interpretation and copyright

Use WCAG for conformance requirements, ARIA for ARIA author requirements and ACT for rule-structure principles. Understanding and APG are informative; an APG deviation is not automatically a WCAG failure. Drafts must remain explicitly labeled and cannot silently impose final requirements.

Write original explanations, link exact criteria and quote briefly only when necessary. Do not reproduce large portions of standards. Separate normative requirements, implementation advice and observations. Advisory improvements must not be asserted as independent A/AA violations.
