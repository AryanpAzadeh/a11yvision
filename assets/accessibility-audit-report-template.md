This review identifies accessibility issues within the tested scope and evidence available to the agent. It is not a certification of WCAG conformance and does not replace manual testing with assistive technologies or testing by disabled users.

## Summary of recorded outcomes

| Outcome | Count in declared scope |
|---|---|
| Confirmed conformance failures | Fill from demonstrated findings |
| Advisory concerns | Separate from conformance failures |
| Needs review | Include unresolved judgment |
| Not tested | Include omitted required tests |
| Cannot verify | Include unavailable evidence/access |
| Passed checks actually performed | Local results with sufficient evidence |
| Not applicable | Established non-applicability |

Use a consistent unit (rule/element/state check), state it and avoid double counting. Also state the combined count of NOT_TESTED and CANNOT_VERIFY. Do not calculate a conformance percentage, score or grade. A local PASS does not establish page/site accessibility.

## Confirmed findings and priorities

Use [the finding template](finding-template.md) for each record. Prioritize task blockers, semantics/names, traps/focus, errors/instructions, visual perceivability and navigation; advisory improvements remain separate. Include exact authority and affected users.

## Changes and verification

Record minimal changes, preserved behavior/localization and evidence from repeated checks. List related regressions checked. Do not turn a patched source defect into a runtime PASS without the required test.

## Unresolved review and coverage

List every NEEDS_REVIEW, NOT_TESTED and CANNOT_VERIFY record, with missing evidence, exact surface/state and next action. Note criteria outside this Phase 1 inventory; do not imply all WCAG A/AA criteria were checked.
